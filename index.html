Accessibility Audit — Tendios Bid
March 2026

This report documents the accessibility issues found during an audit of the Tendios Bid application (bid.tendios.com). Findings are mapped to WCAG 2.1 success criteria and categorised by severity.

📅 Extended audit: 4 March 2026

🌐 Issues Common to All Pages

These issues were confirmed present on every audited page.

SeverityIssueWCAG Criterion
🔴 Critical Buttons with no accessible name — Icon-only buttons (e.g. action menus ⋯, pagination arrows ‹ ›, close/save icons) have no aria-label. Screen reader users cannot identify their purpose.
Fix: add descriptive aria-label attributes to all icon-only buttons.		 4.1.2 Name, Role, Value (A)
🔴 Critical Focus outline removed via CSS (outline: none on :focus) — Keyboard users cannot see which element is currently focused.
Fix: restore visible focus styles, e.g. outline: 2px solid #005fcc.		 2.4.7 Focus Visible (AA)
🟠 Moderate No skip navigation link — Keyboard-only users must tab through the entire sidebar on every page before reaching the main content.
Fix: add a visually-hidden "Skip to main content" anchor at the top of the layout.		 2.4.1 Bypass Blocks (A)
🟡 Minor <iframe> with no title — Every page contains at least one <iframe> without a title attribute. Screen readers cannot convey the purpose of the frame.
Fix: add a descriptive title attribute to all iframes, or role="presentation" if purely decorative.		 4.1.2 Name, Role, Value (A)

📊 Dashboard /

SeverityIssueWCAG Criterion
🟠 Moderate Heading order skipped h1 → h3 — Stat cards use <h3> directly after the <h1>, skipping <h2>.
Fix: use <h2> for section headings or replace stat card headings with styled <p>.		 1.3.1 Info and Relationships (A)
🟡 Minor <iframe> with role="presentation" — If the iframe contains meaningful content, marking it as presentational hides it from assistive technologies.
Fix: assign an appropriate title attribute instead.		 4.1.2 Name, Role, Value (A)
🟡 Minor Potential low-contrast text — The legend label "Publicadas" uses rgb(108, 119, 140) which may fall below the 4.5:1 contrast ratio.
Fix: verify contrast ratio and darken if needed.		 1.4.3 Contrast Minimum (AA)

🔍 Buscar /search

SeverityIssueWCAG Criterion
🟠 Moderate Heading order skipped h1 → h3 — The "Filtros" sidebar section jumps from <h1> to <h3>.
Fix: use <h2> for "Filtros" and <h3> for filter sub-categories.		 1.3.1 Info and Relationships (A)
🟡 Minor 11 elements with tabindex="-1" — These elements are removed from the keyboard tab order. Review to ensure no meaningful content or interactive element is being skipped. 2.1.1 Keyboard (A)

🔔 Alertas /alerts

SeverityIssueWCAG Criterion

🟡 Minor 5 elements with tabindex="-1" — Review to confirm no interactive content is excluded from keyboard access. 2.1.1 Keyboard (A)
